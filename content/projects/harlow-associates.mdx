## Overview

Harlow & Associates came to me with a five-year-old template site that no longer reflected the firm's growth — slow load times, an intake form that routed to a shared inbox nobody checked promptly, and no way to showcase case results without editing raw HTML.

## The challenge

The firm needed three things that didn't naturally coexist in their old setup: a site fast enough to not lose mobile leads on 4G, an intake system their non-technical office manager could actually manage, and an attorney bio system that could scale as the firm added associates without a developer touching code each time.

## Approach

- **Custom ACF field groups** for attorney bios, practice areas, and case results — fully editable from the WordPress admin, no code required for updates.
- **Gravity Forms + conditional routing** so intake inquiries route by practice area directly to the right attorney, with autoresponders confirming receipt.
- **Performance pass** — image optimization, caching, and a lighter theme footprint cut load time from 4.2s to under 1.1s on mobile.
- **Case-results archive** with filtering by practice area, so prospective clients can self-serve relevant outcomes before ever calling.

## Featured code

A piece of this build worth calling out on its own — the conditional routing logic that sends each intake submission to the right attorney based on selected practice area.

<CodePanel
  filename="functions.php — gravity-forms-routing.php"
  repoUrl="#"
  code={`// Route intake submissions by selected practice area
add_filter('gform_notification', function( $notification, $form, $entry ) {
    $practice_area = rgar( $entry, '6' );
    $routing = get_field( 'practice_area_routing', 'option' );

    if ( isset( $routing[ $practice_area ] ) ) {
        $notification['to'] = $routing[ $practice_area ];
    }

    return $notification;
}, 10, 3 );`}
/>

This pattern — mapping a select-field value to a stored routing table via ACF options — is one I've reused across several intake-heavy client sites since. The full repo has the rest of the implementation, including the ACF field registration.
